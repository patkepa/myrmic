# Developing with AI

The documentation is also published as plain text, at two fixed URLs an AI coding assistant can read.

- **[llms.txt](https://book.myrmic.dev/llms.txt)** - an index of every page, with a link to each. Small, and a tool that follows links pulls only the pages it needs.
- **[llms-full.txt](https://book.myrmic.dev/llms-full.txt)** - the entire documentation in one place. Large, so expect it to fill a good part of a context window.

Start with `llms.txt`. Reach for `llms-full.txt` when the tool cannot fetch pages.
